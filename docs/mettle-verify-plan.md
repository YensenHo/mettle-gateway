# Mettle Verify — 中转站信任层（余额真实性验证）MVP 方案

## 0. 一句话定位

> **给 AI API 中转站的买家一个「余额真实性验证」探针** —— 检测中转站是否「余额虚标 / 倍率造假 / 偷偷多扣」，从 0 玩家的真空点切入，最终成为「中转站信任层」。

| 层 | 是什么 | 状态 |

| **CAED**（数据源） | 三角色对抗生成的中文评测样本，护城河=样本会过期需持续再生 | ✅ 已有 v0.3（1493 条） |

## 2. 为什么从「余额真实性验证」切入（不是真伪检测）

调研结论（2026-08-15）：
- ❌ **模型真伪/掺假检测**：已拥挤，7+ 玩家（cctest/veridrop/relay-radar 等，全 2026 年诞生）
- ✅ **余额真实性验证**：**0 玩家真空**（GitHub 搜「余额真实性」= 0 结果）
- ✅ **跑路预警**：0 玩家（仅 VPN/机场圈有 Paolujichang 6742★ 类比，证明需求刚需）

**切入 = 打真空点，避开红海。**

## 3. MVP 范围（V1 最小可验证）

**核心：余额真实性验证探针（单脚本 CLI）**

输入（用户给中转站的）：
1. `base_url` + `api_key`（中转站 OpenAI 兼容接口）
2. 宣称模型（如 `claude-sonnet-4`）+ 宣称倍率（如 1.0）
3. 调用前后的余额（元，用户从中转站后台抄）

输出（检测报告）：
- 本次探针实际消耗 token（usage 字段）
- 按「官方价 × 宣称倍率 × 汇率」计算的**合理扣费**
- 实际扣费（前后余额差）
- **判定**：正常 / 倍率虚标 / 多扣 / 严重造假（倍数超标）

**检测分层（逐版升级，不一次性做全）**：

| 版本 | 检测项 | 原理 | 依赖 |
|------|--------|------|------|
| **V1** | 倍率虚标 / 多扣 | 对照法（实际扣费 vs 官方价×倍率×token） | 官方价目表 + usage 字段 |
| V2 | usage 造假 | 独立 tokenizer 计算真实 token，比对 usage 字段 | tokenizer（tiktoken 等） |
| V3 | 模型真伪 | CAED 对抗样本防规避探针 | CAED 样本引擎 |

## 4. 技术方案（V1 对照法）

```
用户输入: base_url + api_key + 宣称模型 + 宣称倍率 + 前后余额
                │
                ▼
        发标准探针请求 (OpenAI 兼容 /v1/chat/completions)
                │
                ▼
        读 usage 字段 (prompt_tokens + completion_tokens)
                │
                ▼
        合理扣费 = (官方输入价×prompt_tokens + 官方输出价×completion_tokens) / 1e6 × 宣称倍率 × 汇率
        实际扣费 = 前余额 - 后余额
                │
                ▼
        判定 = 实际扣费 / 合理扣费
            < 1.1  → ✅ 正常
            1.1-1.5 → ⚠️ 疑似多扣
            > 1.5  → 🔴 倍率虚标/严重造假
```

**关键设计**：
- 官方价目表内置常见模型（DeepSeek/Claude/GPT/Qwen 等），可 JSON 覆盖
- 汇率默认 7.2 CNY/USD，可配置
- 探针请求固定 prompt + 固定 `max_tokens`，保证可复现

**信任独立性（G2 护栏）**：结论不可购买，只卖「认证收录/曝光」。

| MVP（探针 V1）+ 10 个真实中转站用户愿意用 | 4 周 | 到期 <10 个真实用户 → 砍 |

## 7. 路线图（三件套）

1. **V1 余额真实性验证**（本方案，0 玩家真空）→ 建立品类心智
2. **V2 usage 造假检测**（独立 tokenizer 基准）
3. **V3 模型真伪检测 + CAED 对抗样本持续再生**（防规避差异化，对抗静态探针）
4. **跑路预警/红黑榜**（对标 Paolujichang 6742★ 模式，持续监控 → 公开预警）

最终形态：**「中转站信任持续监控 API」**——买家侧查、卖家侧认证、公开红黑榜。
